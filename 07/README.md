## 🚀 系統六大核心模組

1. 📊 **學習戰情室 (Dashboard)**
   - 知識點雷達圖與掌握度量化分析（電腦五大架構、儲存階層、熱插拔、硬體插槽、CPU指標）。
   - 學生強項與急需補強點對照表。
   - 針對四技二專統測商管群的實戰破題對策。

2. 🔍 **隨堂試卷錯題本 (Error Review & Analysis)**
   - 完整收錄試卷第 1~13 題，清晰還原學生真實作答與老師紅筆眉批。
   - 名師精解、常見陷阱剖析、統測秒殺記憶口訣。
   - 一鍵發起「問 AI 家教這題」，無縫切換到 AI 引導室。

3. 🤖 **1對1 AI 家教引導室 (AI Tutor Chatbot)**
   - 專屬 AI 家教「小智老師」，採用蘇格拉底式引導教學。
   - 內建 4 大失分點情境快捷發問（熱插拔、RAM插槽、MIPS指標、SRAM vs DRAM）。
   - 支援自由發問，專門解答計算機硬體架構與資處科專業科目問題。

4. ✍️ **弱點自適應補強測驗 (Adaptive Practice Quiz)**
   - 針對本次失分的 4 大知識點動態生成 5 道全新考題。
   - 支援線上即時點選作答、提交計分、答對/答錯即時視覺回饋與詳解。

5. 📋 **家教教學日誌與處方箋 (Tutor Action Plan & Parent Notes)**
   - 自動生成正式的家教課堂成果報告。
   - 條列本日 4 大盲點攻堅紀要、指定課後作業、下次進度預告。
   - 內建「給家長的一封信」自動草稿生成器（支援一鍵複製文字傳 LINE、列印為紙本或 PDF 處方箋）。

6. ➕ **考卷與題庫管理系統 (Exam & Question Manager)**
   - 支援家教老師自由登錄新題目（如試卷第 2 面 Q14~Q25 或其他隨堂考卷）。

## 💻 快速啟動與使用說明

### 方法一：直接點擊開啟
直接使用任何瀏覽器（Chrome, Edge, Firefox, Safari）雙擊打開 `index.html` 即可立即使用。

### 方法二：透過本機 Python 簡易伺服器啟動
目前已為您在背景啟動服務，瀏覽器訪問：
```
http://localhost:8088/index.html
```
若需手動重啟：
```powershell
python -m http.server 8088
```
